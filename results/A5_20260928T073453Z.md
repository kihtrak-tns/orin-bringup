## Installer review (why the install command is not the plain `--silent`)
Read `linux_install_release.sh` from the extracted installer before running
anything:
- `--silent` makes `asksure` return yes to **every** prompt.
- **CUDA detection would fail:** it looks for `nvcc` or
  `/usr/local/cuda/version.txt`, and neither exists. In silent mode it then
  auto-runs `sudo apt-get install nvidia-jetpack-dev` (6.2.3+b81, the whole
  JetPack dev stack).
- **`nvcc` is needed anyway:** the SDK's `zed-config.cmake` does
  `find_package(CUDA 12.6 REQUIRED)` (FindCUDA needs `nvcc`), so the step 7
  `zed-ros2-wrapper` build would fail without it.
- **Power mode:** the MAXN / `jetson_clocks` step (`enable_maxperf_jetson`)
  is **commented out** in this installer version, so it won't change
  nvpmodel.
- **System changes it will make (sudo):** udev `99-slabs.rules`; sysctl
  `60-zed-buffers.conf` (UDP rmem 1 MB, for streaming); journald
  `Storage=persistent` with `SystemMaxUse=500M` (backs up `journald.conf`);
  copies `zed_media_server_cli.service` but does **not** enable it; sets
  `notify_disable=True` in the nvpmodel indicator (GUI over-current popup);
  apt dependencies. Optional Python API: pip installs into the system
  python3, skipped below since A5 doesn't need it.

ssh -t dev-orin 'sudo apt-get install -y cuda-nvcc-12-6 && /usr/local/cuda/bin/nvcc --version | tail -1 && cd ~/zed_install && ./ZED_SDK_Tegra_L4T36.5_v5.5.0.zstd.run -- silent skip_python'

adds ~128 MB plus `cuda-nvvm`/`cuda-crt`. With it, the installer detects
CUDA 12.6 itself and doesn't pull `nvidia-jetpack-dev`.
